# SaunaUndGrieche24

**SaunaUndGrieche24** ist eine kleine PHP‑Webseite, die einfache Controller‑ und View‑Strukturen nutzt.  
Das Projekt wird privat betrieben und ist **nicht als Open‑Source‑Software lizenziert**.

Externe Nutzer können den Code ansehen, aber **nicht selbst deployen**.  
Beiträge sind dennoch willkommen – über Issues oder Pull Requests.

---

## 📝 Issues erstellen

Wenn du Fehler findest oder Verbesserungen vorschlagen möchtest:

1. Öffne den Tab **Issues**
2. Klicke auf **New Issue**
3. Beschreibe klar, was du beobachtet hast oder was du dir wünschst

---

## 🔧 Pull Requests einreichen

Wenn du selbst Änderungen vorschlagen möchtest:

1. Forke das Repository  
2. Klone deinen Fork lokal  
3. Erstelle einen neuen Branch für deine Änderung  
4. Nimm deine Änderungen vor  
5. Committe und pushe deinen Branch  
6. Öffne einen **Pull Request** zurück in dieses Repository

Pull Requests werden geprüft und ggf. gemerged.

---

## 📦 Deployment

Das Deployment erfolgt ausschließlich durch den Repository‑Owner.  
Externe Nutzer können **nicht** deployen.

Nach dem Merge eines Pull Requests wird die Seite automatisch aktualisiert.

---

## 📄 Lizenz

Dieses Projekt hat **keine öffentliche Lizenz**.  
Der Code darf **nicht kopiert, weiterverwendet oder kommerziell genutzt** werden.
